# Publications

A publication is a set of metadata generated from a repository version so that clients such as `dnf` or `pip` can consume it. Open **Content Management → Publications** to create a publication from a repository or delete one. Click a publication to open its page: **Details** shows the repository version it was published from, the distributions serving it and its settings; **Access** grants users and groups roles on it.
