# Domains

Domains split one Pulp installation into isolated tenants. For what a domain _is_ (and how it
affects content URLs), see [Domains](../concepts/domains.md). This page covers the admin side.

Manage them under **System Management → Domains**.

## Common tasks

- **Create / edit / delete a domain.**
- **Configure its storage backend** — local, S3, or Azure.
- **Migrate** a domain's storage.

When domains are disabled on the server, the page shows a disabled empty state. Users, groups and
roles remain global across all domains.
