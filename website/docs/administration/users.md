# Users

Manage the people who can sign in to Pulp, under **Administration → Users**.

## Common tasks

- **Create / edit a user** — username, password, name, email, and superuser flag.
- **Add a user to groups** — the user detail page has a **Groups** tab.
- **Delete a user.**

Users are global — they are not scoped to a [domain](./domains.md). What a user can actually do is
decided by the [roles](./roles-and-permissions.md) granted to them or their
[groups](./groups.md). See [Access control](../concepts/access-control.md).
