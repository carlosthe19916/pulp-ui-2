# Alternate content sources (ACS)

An ACS registers a **closer or faster mirror** that Pulp prefers when fetching binaries within a
domain — for example a local-disk copy, or another Pulp. It speeds up on-demand downloads without
changing your repositories.

Manage them under **System Management → Alternate Content Sources** (shown when an ACS-capable
plugin, such as RPM or File, is installed).

## Common tasks

- **Create / edit** an ACS (a Remote plus the ACS object).
- **Refresh** it to index the mirror's available content.
