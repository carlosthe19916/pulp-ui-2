# Groups

Groups collect users so you can assign [roles](./roles-and-permissions.md) to many people at once.
Manage them under **Administration → Groups**.

## Common tasks

- **Create / delete a group.**
- **Add or remove members** — the group detail page has a **Users** tab.
- **Grant roles to the group** — everyone in it inherits them.
