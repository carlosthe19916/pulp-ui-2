# OSTree repository manager

The content server for rpm-ostree and image mode (Fedora CoreOS, RHEL image mode, Silverblue, IoT). Mirror the refs you deploy, import the commits your build produces, and point `ostree` at Pulp. This is not a package repository.

```text
ostree / rpm-ostree --> Pulp --+-- ostree-upstream  the refs you named
                               +-- ostree-hosted    commits you imported
```

There is no `ostree push`. A distribution serves the repository version in `archive` format. No publication.

You need Pulp with `pulp_ostree` and the `ostree` tool. [`examples/ostree`](https://github.com/carlosthe19916/pulp-ui-2/tree/main/examples/ostree) mirrors `https://fixtures.pulpproject.org/ostree/small/` (`stable` and `rawhide`) and imports a commit of its own. `setup.sh` creates the objects.

## Mirror refs

A remote, a repository that syncs from it, and a distribution. Only the remote has settings that matter: **Include refs** is the set, and a name that matches nothing syncs nothing without an error. **Commit depth** `0` fetches the latest commit only.

## Import a disconnected build

Image builders emit an `archive`-mode repository. `ostree init --mode=archive` is the format Pulp accepts.

```bash
cd examples/ostree
ostree init --repo=build/hello-repo --mode=archive
ostree commit --repo=build/hello-repo --branch=hello/stable --tree=dir=hello --subject="hello 1.0.0"
tar -cf build/hello-repo.tar -C build hello-repo
```

Import the tarball onto the hosted repository. **Repository name** must be the tarball's top directory (`hello-repo`). Leave **Ref** empty to import every ref. Set it to add commits on top of an existing ref. See [Import commits](https://github.com/pulp/pulp_ostree/blob/main/docs/user/guides/import-commit.md).

```bash
ostree remote add --no-gpg-verify pulp-hosted \
  http://localhost:5003/pulp/content/default/ostree-hosted/
ostree pull pulp-hosted hello/stable
```

`--no-gpg-verify` is for unsigned commits. Signed commits omit it. On an rpm-ostree system, `rpm-ostree rebase pulp-hosted:hello/stable` deploys the ref.

## What clients download

**Compute static deltas** (on by default) generates deltas between commits, so an update is smaller than a full pull.

Point the distribution at a repository version to keep clients on a known-good commit while you test the next import. See [What clients see](../concepts/what-clients-see.md). This import is the disconnected path. The generic exporter is for other plugins. See [Disconnected and multi-site](../concepts/disconnected.md).

## Troubleshooting

| Symptom | Cause and fix |
| ------- | ------------- |
| Import fails: repository not found in archive | **Repository name** must match the tarball's top directory. |
| Import fails on the repository format | Only `archive` mode. `ostree init --mode=archive`. |
| `GPG verification enabled, but no signatures` | The commits are unsigned. `--no-gpg-verify`, or sign them. |
| Sync finds nothing | **Include refs** matches no upstream ref. |
