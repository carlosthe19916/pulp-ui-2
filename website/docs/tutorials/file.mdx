# Generic file repository

Raw artifacts: ISOs, installers, vendor binaries. Also the way one Pulp mirrors another's files. There is no pull-through cache, and there is no package manager. The client is `curl`.

```text
curl --> Pulp --+-- files-upstream  sync of a PULP_MANIFEST
                +-- files-hosted    files you upload
```

A file remote syncs a **`PULP_MANIFEST`**: a CSV of `path,sha256,size` for each file next to it. The remote URL is that file, not its directory. Any web server can host one. **On demand** stores the manifest now and each file on first download.

A **Git** remote is the other source: files from a Git ref, for a tree that is not already published as a manifest.

The repository needs a **publication**. Auto-publish writes one on every change, including a new `PULP_MANIFEST`. A distribution with no publication 404s. Because every publication writes that manifest, a second Pulp syncs `files-hosted` by pointing a File remote at `http://localhost:5003/pulp/content/default/files-hosted/PULP_MANIFEST`.

[`examples/file`](https://github.com/carlosthe19916/pulp-ui-2/tree/main/examples/file) uses the fixture `https://fixtures.pulpproject.org/file/PULP_MANIFEST`. `pulp_file` ships with pulpcore.

```bash
curl -O http://localhost:5003/pulp/content/default/files-hosted/hello-1.0.0.tar.gz
curl -O http://localhost:5003/pulp/content/default/files-hosted/PULP_MANIFEST
sha256sum -c <(awk -F, '{print $2 "  " $1}' PULP_MANIFEST)
```

Re-uploading the same relative path replaces the file in a new repository version. Compare against the current manifest. Point the distribution at a version to freeze the tree. See [What clients see](../concepts/what-clients-see.md). An RBAC or certificate [content guard](../concepts/operating.md#content-guards) is how these URLs stop being anonymous.

## Troubleshooting

| Symptom | Cause and fix |
| ------- | ------------- |
| `404` for a file you uploaded | No publication. Auto-publish, or publish. |
| Sync fails reading the manifest | The remote URL must be the `PULP_MANIFEST` file itself. |
| Checksum mismatch after a re-upload | The path now points at the new file. Check the current manifest. |
