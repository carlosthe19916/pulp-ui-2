# npm repository manager

Cache the public registry for installs, and publish your own scope to Pulp. There is no group repository: `.npmrc` sends the scope to the hosted registry and everything else to the cache.

```text
npm --> Pulp --+-- npm-proxy   pull-through --> registry.npmjs.org
               +-- npm-hosted  hosted (@example/*)
```

:::caution[Tech preview]

npm pull-through is a tech preview in `pulp_npm`. Installs work. Hosted metadata has a gap called out below.

:::

You need Pulp with `pulp_npm`, npm, and [`examples/npm`](https://github.com/carlosthe19916/pulp-ui-2/tree/main/examples/npm). `setup.sh` creates the objects. URLs are the local backend, domain `default`.

## Cache and host

The pull-through remote belongs on the **distribution**. The repository's own remote stays empty.

| Object | What matters |
| ------ | ------------ |
| Remote `npm-proxy` | URL `https://registry.npmjs.org/`. |
| Repository `npm-proxy` | No remote. |
| Distribution `npm-proxy` | Base path `npm-proxy`, repository `npm-proxy`, pull-through remote `npm-proxy`. |
| `npm-hosted` | Repository and distribution, no remote. Base path `npm-hosted`. |

| Purpose | URL |
| ------- | --- |
| Read (`npm install`) | `http://localhost:5003/pulp/content/default/npm-hosted/` |
| Write (`npm publish`) | `http://localhost:5003/npm/default/npm-hosted/` |

The publish URL is `<pulp>/npm/<domain>/<base-path>/`. Without domains, drop `<domain>/`.

```ini title=".npmrc"
registry=http://localhost:5003/pulp/content/default/npm-proxy/
@example:registry=http://localhost:5003/pulp/content/default/npm-hosted/
//localhost:5003/npm/default/npm-hosted/:_auth=YWRtaW46cGFzc3dvcmQ=
```

`_auth` is the base64 of `user:password` (`printf admin:password | base64`) for a user who can modify `npm-hosted`. The key is the publish URL **without the scheme**, ending in `/`. The example [`.npmrc`](https://github.com/carlosthe19916/pulp-ui-2/tree/main/examples/npm/.npmrc) reads the values from the environment.

```bash
cd examples/npm/hello-lib
npm publish --@example:registry=http://localhost:5003/npm/default/npm-hosted/
cd ../hello-app && npm install && node index.js
```

`package-lock.json` still records `registry.npmjs.org` for public packages. npm rewrites that to your registry on install.

Reads are anonymous until the distribution has a [content guard](../concepts/what-clients-see.md). A CI user needs permission to modify the hosted repository. See [Who can push](../concepts/access-control.md). Point the distribution at a repository version to freeze what installs resolve.

## Troubleshooting

| Symptom | Cause and fix |
| ------- | ------------- |
| `ENEEDAUTH` on publish | The `.npmrc` key must be `//<host>/npm/<domain>/<base-path>/:_auth`. |
| Publish goes to `/pulp/content/...` | `--registry` does not apply to a scoped package. Pass `--@example:registry=<publish URL>`. |
| A published package's dependencies are missing | `pulp_npm` 0.10 does not list a hosted package's `dependencies` in its metadata. Declare them in the app, or keep the library dependency-free. |
| `404` installing a public package | The proxy distribution has no pull-through remote, or the remote URL is wrong. |
