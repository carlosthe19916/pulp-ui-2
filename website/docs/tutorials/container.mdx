# Container registry

Three jobs, three objects. Picking the wrong one is the usual failure.

```text
podman --> Pulp --+-- docker-hub/<image>   pull-through cache of Docker Hub
                  +-- a synced image       tags you named ahead of time
                  +-- hello-app            created by podman push
```

Pull-through is a tech preview in `pulp_container`. You need Pulp with `pulp_container`, podman 4 (or docker), and [`examples/container`](https://github.com/carlosthe19916/pulp-ui-2/tree/main/examples/container). The registry host is `localhost:5003`. With domains, the domain is the first path segment: `localhost:5003/default/<image>`. A path without the domain fails.

The local backend sets `TOKEN_AUTH_DISABLED=True`, so the registry uses basic auth. A production server usually runs Pulp's token server. A `500` from `/v2/` means token auth is on and no token server is configured. See [Authentication](https://pulpproject.org/pulp_container/docs/admin/learn/authentication/).

## Cache a registry on pull

A **Container (pull-through)** remote plus a **Container (pull-through)** distribution. There is no repository to create and no sync. Pulp creates a repository and a distribution per image as clients pull. **Include repositories** and **Exclude repositories** limit what may be cached (`library/*`).

| Docker Hub | Through Pulp |
| ---------- | ------------ |
| `docker.io/library/busybox:1.37` | `localhost:5003/default/docker-hub/library/busybox:1.37` |
| `docker.io/pulp/pulp:latest` | `localhost:5003/default/docker-hub/pulp/pulp:latest` |

Official images need the `library/` prefix.

## Pin a set of tags

A normal **Container** remote: registry URL, **Upstream name** (`library/busybox`), **Include tags** (`1.37*`). A **Container** repository uses that remote. Sync, then serve it with a **Container** distribution (not the pull-through type). This is the job when clients must not be able to pull whatever they ask for.

## Push images

`podman push` creates the repository and the distribution. You do not create them first, and you cannot upload a manifest. Blobs, manifests and tags arrive by push or by sync.

```toml title="/etc/containers/registries.conf.d/pulp.conf"
[[registry]]
location = "localhost:5003"
insecure = true
```

Docker uses `"insecure-registries": ["localhost:5003"]` in `/etc/docker/daemon.json`.

```bash
podman login localhost:5003 -u admin -p password
cd examples/container
podman pull localhost:5003/default/docker-hub/library/busybox:1.37
podman build -t localhost:5003/default/hello-app:1.0.0 hello-app
podman push localhost:5003/default/hello-app:1.0.0
podman run --rm localhost:5003/default/hello-app:1.0.0
```

**Private** on a distribution requires a login to pull. Pushing requires a user allowed to create repositories in that namespace. The first push to a new prefix creates the namespace. Grant a role on the namespace to limit who can push under it.

Namespace storage quotas and tag expiry, the way Harbor and Quay do them, are not a Pulp feature. Prune the repository and [reclaim orphans](../concepts/disk.md).

## Promote, sign, build

A tag is a name pointing at a manifest digest. Untagging removes the name and leaves the manifest. **Copy tags** and **Copy manifests** copy references into another repository, which is how you promote `:1.2.0` to a release repository without pushing again.

A [signing service](../concepts/operating.md#signing) on the repository signs manifests as they are added. **Sign images** signs existing tags. To mirror a registry that publishes sigstore signatures, set the remote's sigstore URL so the sync fetches them.

:::info[Not yet in Pulp UI]

Rejecting an unsigned pull. Pulp stores signatures. Enforcement is client policy (`cosign`, podman). See [image signing](https://pulpproject.org/pulp_container/docs/admin/guides/sign-image/).

:::

**Build image** builds from a Containerfile inside Pulp and tags the result. It is a tech preview.

## Troubleshooting

| Symptom | Cause and fix |
| ------- | ------------- |
| `http: server gave HTTP response to HTTPS client` | Mark `localhost:5003` insecure, or pass `--tls-verify=false`. |
| `500` from `/v2/` | Token auth is enabled and no token server is configured. |
| `unauthorized` on push | `podman login` with a user allowed to push to that namespace. |
| `manifest unknown` through the cache | The image is not on that registry under that name, or **Exclude repositories** filters it. Official images need `library/`. |
| Image path without the domain fails | With domains, every path starts with the domain. |
