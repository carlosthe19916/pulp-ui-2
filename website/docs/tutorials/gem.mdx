# RubyGems repository manager

Cache rubygems.org, and publish gems of your own. Unlike Python, a gem distribution serves a **publication** (the compact index), and there is no combined index: the Gemfile lists both sources. Unlike Maven, npm and Python, a pull-through cache does not add the downloaded gems to a repository. The distribution has no repository. The gems show up as content.

```text
gem / bundler --> Pulp --+-- rubygems-proxy  pull-through --> index.rubygems.org
                         +-- gems-hosted     your gems, after a publication
```

You need Pulp with `pulp_gem`, Ruby, and [`examples/gem`](https://github.com/carlosthe19916/pulp-ui-2/tree/main/examples/gem). `setup.sh` creates the objects.

| Object | What matters |
| ------ | ------------ |
| Remote `rubygems-proxy` | URL `https://index.rubygems.org/`, policy **On demand**. |
| Distribution `rubygems-proxy` | No repository. Pull-through remote `rubygems-proxy`. |
| Repository `gems-hosted` | No remote. |
| Distribution `gems-hosted` | Repository `gems-hosted`. It serves the latest **publication**, so publish after every upload. |

`gem push` is not implemented. Upload the `.gem`, then publish. To sync a set ahead of time instead of caching on install, give a repository the remote, set **Gem selection** (for example `rails` → `~> 7.1`), sync, and publish.

```bash
gem install --clear-sources --source http://localhost:5003/pulp/content/default/rubygems-proxy/ rainbow
cd examples/gem/hello-lib && gem build hello_pulp.gemspec
```

```ruby title="hello-app/Gemfile"
source "http://localhost:5003/pulp/content/default/rubygems-proxy/"

source "http://localhost:5003/pulp/content/default/gems-hosted/" do
  gem "hello_pulp", ">= 1.0"
end
```

A `source` block pins those gems to that source, so a same-named gem on rubygems.org cannot replace yours.

Point the distribution at an older publication to keep serving it. See [What clients see](../concepts/what-clients-see.md).

## Troubleshooting

| Symptom | Cause and fix |
| ------- | ------------- |
| A newly uploaded gem is not found | The repository was not published after the upload. |
| `gem push` fails | Upload the `.gem`. Pulp does not implement the push API. |
| `Could not find gem` for a public gem | The proxy distribution has no pull-through remote, or the remote URL is wrong. |
| Bundler resolves your gem from rubygems.org | The gem is outside the hosted `source ... do` block. |
