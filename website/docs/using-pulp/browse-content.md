# Browse and search content

See what's inside your repositories.

## Where

- **A repository's Content tab** — the content in its latest (or a chosen) version.
- **Content Management → Content** — browse and search content units across all repositories.

## What you can do

- Search and filter by type.
- Find **orphaned** content (not in any repository).
- Filter by **repository version**, and compare versions (a **diff** of what was added/removed).
- Open a content unit to see its **Artifacts** and the **Repositories** that reference it.
- Shortcuts to **Add to repository**, **Remove from this repository**, and **Upload content**.
